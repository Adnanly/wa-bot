## 📝 HOW TO GET DISCORD WEBHOOKS:

1. Open your Discord server
2. Go to Server Settings > Integrations
3. Click "Create Webhook"
4. Choose a channel for logs
5. Copy webhook URL
6. Paste in .env file above

### Recommended Setup:
- **#bot-logs** channel → MAIN, SYSTEM
- **#messages** channel → MESSAGES
- **#groups** channel → GROUPS, JOIN_LEAVE
- **#media** channel → PROFILE_PIC, STATUS
- **#commands** channel → COMMANDS
- **#errors** channel → ERRORS, DELETED
